## 1.星图界面

### 1.1 Dataset 下拉菜单对比度不足

Dataset切换下拉框背景色和字体颜色相近

### 1.2 星图缩放方式

鼠标滚轮放大更符合用户直觉，能够放大看清关系与内容。

当前首页星图没有明显的滚轮/触控板缩放手势或专用缩放控件，用户难以放大查看密集关系。对桌面端用户而言，在图谱区域使用滚轮或触控板进行缩放更符合探索地图的习惯。建议仅在鼠标位于图谱区域时响应滚轮缩放，并提供缩放比例、放大、缩小和重置视图操作；避免滚轮操作同时触发页面滚动。

### 1.3 图谱缺少清除选择的直接操作

选中化合物后，点击图谱空白区域不会关闭化合物卡片或清除高亮，用户只能寻找卡片右上角的关闭按钮，或执行其他选择操作。建议支持点击图谱空白处清除当前选择，并保留关闭按钮和 Escape 键作为替代方式。

目前实现了一个边栏的Clear Highlights按键，但是太蠢了，移除之，改成点击空白处Clear Highlights

### 1.4 图谱横向拖拽存在明显的位移/阻尼不一致  

横向拖动节点时，光标移动距离与画布实际位移不一致，尤其在大幅拖拽时会产生“拖不动”或被削弱的感觉。

### 1.5 Graph controls 菜单混入了导航和选择操作

Graph Control里的Clear Selection和Open Search Library这两个按钮应该和Graph Control和Downloading Table平级，而不是在Graph Control级别下。

### 1.6 反应关系卡片中的下载按钮未对齐

点击反应关系后的下载图标未对齐

### 1.7 反应关系卡片出现元素重叠

元素重叠。

### 1.8 拖拽星图时出现元素闪烁

## 3.下载队列界面

### 3.1 下载格式问题

四种下载格式都是下出来csv。然后下载格式里没有csv，但是有单独的export csv按键。很奇怪。

方案：

将下载页改为真正的导出配置区，支持 `CSV`、`FASTA`、`TSV`、`TXT`、`XLSX`，默认选中 CSV；所有导出按钮都读取当前格式配置，并在下载前显示最终文件名和格式。

在其他格式尚未实现前，将其设置为禁用状态，并标注“暂未实现”，同时把当前可用的 CSV 设为明确的默认选项。不要让不可用选项看起来像可以正常导出。

### 3.2 下载配置和队列条目的选中状态不清晰

没有选中和取消的提示。也没有实现。

### 3.3 下载页底栏与背景区分不足

磨砂效果让底栏不太清晰，用户不容易判断其边界和可操作区域。

考虑提高底色不透明度，增加边框和阴影，保证对比度。
